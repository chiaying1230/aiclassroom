# Apps Script 後端備份

這個資料夾是 AI 課堂後端程式的**備份**。真正執行的程式在 Google Apps Script 專案裡，改這裡不會影響網站。

| 檔案 | 內容 | 負責 |
|---|---|---|
| `Code.gs` | 網頁 API 入口、教師帳號與登入、課程、試算表讀寫、作答與批改流程、課堂討論、教材庫的課程權限 | 擁有者 |
| `ai.gs`（專案裡叫「AI 功能.gs」） | 所有呼叫 Gemini 的程式：批改、建議類別、分類、摘要 | AI 夥伴 |
| `RAG_Admin.gs` | 教材庫：上傳 PDF、切段、啟用與封存 | 擁有者 |
| `RAG_Chat.gs` | AI 助理對話 | 擁有者 |
| `ai_instant.gs` | 學生作答相關的 AI：即時回饋（回饋風格）、學習診斷 | AI 夥伴可調整提示詞 |

`RAG_Setup.gs`、`RAG_Import.gs`、`RAG_AutoSearch.gs` 和教材預覽（`previewRAGForTeacher`）尚未備份。

## 課程與帳號（2026/10 改版）

- 試算表多了三張工作表：**課程**、**教師帳號**、**教材課程**；**題目**多了一欄「課程ID」。
- 管理員帳號是 `admin`，密碼是指令碼屬性的 `TEACHER_PASSWORD`。其他教師的帳號由管理員在網站的「帳號管理」新增，密碼只存雜湊值。
- 改版前的題目、作答和教材都歸在預設課程「人工智慧（小教）」，課程ID 存在指令碼屬性 `DEFAULT_COURSE_ID`。

### 第一次部署這個版本

1. 先備份試算表：打開試算表，「檔案 → 建立副本」。
2. 在 Apps Script 把 `Code.gs` 和 `RAG_Chat.gs` 的內容整份換成這裡的版本，儲存。`ai.gs`、`RAG_Admin.gs` 不用動。
3. 函式選單選 `setupSystem`，按「執行」。執行紀錄會顯示預設課程的**加入代碼**。
4. 函式選單選 `checkTeacherApiHandlers`，按「執行」，確認沒有錯誤。
5. 「部署 → 管理部署作業 → 鉛筆 → 版本選『新版本』→ 部署」。網址不會變。
6. 後端部署好之後，網頁才能換成新版（新網頁需要新後端）。
7. 把預設課程的加入代碼或學生連結給原本的學生，他們第一次打開新網頁時要輸入一次。

### 2026/10/19 修正

- 開頭是 `=`、`+`、`-`、`@` 的文字（例如學生用「- 」條列的回答）會被試算表當成公式，顯示成 `#ERROR!`。現在寫入前都會存成純文字。
- 已經變成 `#ERROR!` 的舊資料：貼上新的 `Code.gs` 後執行一次 `setupSystem`（或單獨執行 `repairFormulaCells`）就會修回原本的文字。
- 管理員密碼太簡單時，網站會提醒管理員。學號與姓名加上長度限制。

- 新增「複製題目」（`copyQuestions`）：把題目複製到自己的其他課程或同一門課，一律存成草稿、清空截止時間，不複製學生作答。

步驟：`Code.gs` 整份換成新版 → 執行 `setupSystem` → 部署新版本。其他檔案不用動。

### 2026/10/22：作答歷程、即時 AI 回饋、自動分類

- **作答歷程**：學生重新送出時，舊的版本存到新的「作答歷程」工作表，學生和老師都看得到每一次的回答、AI 回饋和老師評語。
- **即時 AI 回饋**：老師在每一題選回饋風格（鼓勵與提示、提問引導思考、對照評分規準、簡短鼓勵、自訂）和補充指示。學生送出後馬上看到回饋；AI 忙碌時由背景工作稍後補上。同一位學生同一題每小時最多 8 次。
- **自動分類**：開啟的題目，學生送出後約 1 分鐘內由背景工作分類並標成已確認；還沒有類別時，滿 5 份回答自動建立類別。
- **背景工作**：`setupSystem` 會建立每分鐘執行 `autoProcessTick` 的觸發條件。沒有新回答時只讀快取就結束，幾乎不花執行時間。
- 題目表多了「即時回饋風格、回饋補充指示、自動分類」三欄；學生作答表多了「AI即時回饋、繳交次數」兩欄。舊題目預設都是關閉。

步驟：

1. `Code.gs` 整份換成新版。
2. 新增一個指令碼檔案，命名為 `ai_instant`，貼上 `ai_instant.gs` 的內容。`AI 功能.gs` 不用動。
3. 執行 `setupSystem`。這次會多要求一項授權（管理觸發條件），請按允許。執行紀錄最後會寫「自動處理的觸發條件已建立」。
   觸發條件會用執行 `setupSystem` 的人的帳號跑，請由專案擁有者執行。
4. 執行 `checkTeacherApiHandlers` 確認沒有錯誤，再部署新版本。

- **學習診斷**：教師系統的「學習診斷」分頁。AI 讀全班最新的回答（最多 150 份），整理整體狀況、多數已掌握的概念、待釐清的概念（含是哪些學生）、普遍缺少的部分、下一步教學建議和一題確認理解的提問。每次分析存一列在「學習診斷」工作表。至少要 3 份回答。

注意：Gemini 免費版每分鐘的呼叫次數有限。全班同時送出時，部分即時回饋會晚一兩分鐘才出現在學生的作答紀錄，這是正常的。

## 更新備份

在 Apps Script 改好並部署新版本後，把該檔案的內容更新到這裡，commit 訊息寫清楚改了什麼。

## 不放進這裡的東西

API 金鑰（`GEMINI_API_KEY`）、教師密碼（`TEACHER_PASSWORD`）都只存在 Apps Script 的「專案設定 → 指令碼屬性」，不要寫進程式或這個資料夾。
