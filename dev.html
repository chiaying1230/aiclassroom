修改後端的流程

  1. 在 Apps Script 修改，用測試函式確認結果。
  2. 執行 checkTeacherApiHandlers，確認教師功能都存在。
  3. 「部署 → 管理部署作業 → 編輯 → 新版本」，網站才會用到新程式。
  4. 把改好的檔案更新到 GitHub 的 apps-script/，留下版本紀錄。

注意

API 金鑰與教師密碼只存在 Apps Script 的「指令碼屬性」，不要寫進程式碼，也不要上傳到 GitHub。這個儲存庫是公開的。
